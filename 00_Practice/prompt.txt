LEETCODE PROBLEM SOLUTION GENERATOR PROMPT
===========================================

Use this prompt template to generate comprehensive solution files for new LeetCode problems:

---

**PROMPT TEMPLATE:**

I'm working on LeetCode problem [PROBLEM_NUMBER]: [PROBLEM_NAME]. Please create a complete solution package with the following structure:

**Problem Details:**
- Problem Number: LC_[XXX]_[ProblemName]
- Category: [Arrays_Hashing/Two_Pointers/Sliding_Window/Stack/Binary_Search/Linked_List/Trees/etc.]
- Difficulty: [Easy/Medium/Hard]
- Problem Statement: [Paste the complete problem statement here]

**Required Files to Generate:**

1. **Main Solution File** ([ProblemName].java):
   - Multiple solution approaches (at least 2-3 different methods)
   - Each approach in separate class with descriptive names (Solution1, Solution2, etc.)
   - Comprehensive comments explaining time/space complexity
   - Test cases in main method with expected outputs
   - Clean, well-documented code

2. **Solution Steps File** (Solution_Steps.txt):
   - Problem description
   - Multiple approaches (3-5 different methods)
   - For each approach include:
     * Intuition explanation
     * Step-by-step breakdown (Step 1, Step 2, etc.)
     * Time complexity analysis
     * Space complexity analysis
     * Key insights and patterns
   - Interview tips and trade-offs between approaches
   - Format exactly like existing Solution_Steps.txt files

**Requirements:**
- Use Java programming language
- Follow clean code principles
- Include multiple solution approaches (brute force → optimized)
- Provide detailed complexity analysis
- Add meaningful comments and documentation
- Structure code for interview readiness
- Include edge cases in testing

**File Structure to Create:**
```
[Category]/Problems/LC_[XXX]_[ProblemName]/
├── [ProblemName].java           (Main solution file)
├── Solution_Steps.txt           (Explanation file)
```

**Example Usage:**
Replace the bracketed placeholders with actual values:

**Sample Problem Statement Format:**
```
Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

Example 1:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Constraints:
- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- Only one valid answer exists.
```

1. Brute Force approach (for comparison)
2. Optimized approach (main solution)
3. Alternative approaches (if applicable)
4. Advanced/Follow-up approaches (if mentioned in problem)
